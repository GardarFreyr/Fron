# FRÓN fasteignamiðlun – hugmynd að forsíðu

Hönnunartillaga frá Garðar Vefur, án skuldbindingar. Þetta er **ekki** opinber vefur FRÓN fasteignamiðlunar og hönnunin hefur ekki verið samþykkt af FRÓN.

Staðfestar upplýsingar eru sóttar af núverandi vef, [fron.is](https://www.fron.is/): sex eignir úr söluskrá (sóttar 15. október 2026, hvert spjald opnar eignina á fron.is), starfsfólk með myndum og titlum, heimilisfang, símar, netföng og opnunartími. Sími og netfang eru virkir `tel:`/`mailto:` hlekkir.

Sýnishorn:
- Eignaleitin er ekki tengd. fron.is tekur ekki við síum í slóð, svo „Leita að eign“ opnar núverandi söluskrá.
- Verðmatsformið sendir ekkert. Það sýnir sýnishorn af staðfestingu ásamt síma og netfangi.
- Myndir í hetjuhluta og verðmatshluta eru af Unsplash (Ben Eaton; SaiKrishna Saketh Yellapragada) og sýna ekki eignir á skrá.

Síðan er merkt `noindex` á meðan hún er tillaga.

Kyrrstæð síða: `index.html`, `img/`.
